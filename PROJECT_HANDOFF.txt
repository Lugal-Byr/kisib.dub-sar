WHAT WE AGREED
Keep the window boring and make the evidence excellent.
Use a plain Win95 Explorer layout: branching tree left, certificate list right, details below. Familiar folders, readable names and simple controls; no modern dashboard redesign.
Keep each feature's Microsoft term, Learn URL and documented/to test tag. Distinguish documented API behavior, custom app behavior, hosted test evidence and user-PC acceptance.
Keep three separate observations: certificate exists; an application used it; a policy actually stopped it. Never infer one from another.
The larger evidence path is certificate > issuing authority > organization > country/affiliation > observed application use > enforcement result.
Each connection requires evidence and a visible source. Unresolved connections stay unknown.
Tags stack: an issuer/certificate can belong to several groups at once.
Separate the user's requested policy from verified Windows enforcement. A requested block is not a verified block; a stored certificate is not proof of active use or universal software usability.
The user wants configurable country, monarchy, organizational and other tag groups. C= is a certificate declaration, not proof of ownership, political control or compromise.
Do not promise universal application/browser capture or infer certificate purpose from an arbitrary syscall.
