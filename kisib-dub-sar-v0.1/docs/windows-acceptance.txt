not-before, not-after, SHA-1, SHA-256. Names use CN then O. C= is the certificate's
own claim; full DNs stay in Details/Issuer. Find preserves paths and store counts.

name in a merged store. Failed reads must not appear empty. Four optional switches
start unchecked; no grouping or incident menu exists.
